# Pek.RMail · 项目接续指南

> **开工先读（存在则读，按序）**：`.github/copilot-instructions.md` → 本文 → `docs/用户档案.md` → `docs/项目记忆.md` → `docs/决策记录.md` 最新节。
> **机器自愈（有则快跑）**：`tools/continuity/install-global-instruction.ps1`（幂等；打开项目时 `.vscode/tasks.json` 也会自动跑）。

## 1. 项目速览

- 定位：C# `Pek.Mail` 的 Rust 实现（**邮件发送库**，crate `pek-rmail`）。
- 参照：`G:\Code\Pek.FrameWork\Pek.Mail`（MailKit / Smtp 两套引擎、EmailBox、附件、多账号 fallback、邮箱后缀路由、发送队列）。
- 后续：短信能力另起项目，当前不实现。
- 远程仓库：`https://github.com/RemoteAll/Pek.RMail.git`（remote 名 `main`，分支 `main`）。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
$env:PYTHONIOENCODING='utf-8'
cargo check --offline
cargo test --offline
cargo clippy --all-targets --offline
```

- 日常写码用 `cargo check`；本地调测需要二进制时用 `cargo build --profile fast`；`--release` 只用于发布。
- 依赖下载走项目内 `.cargo/config.toml`（rsproxy 镜像）。

## 3. 目录约定

```
src/{lib,error,settings,message,sender/,queue,mailer}.rs
res/Mail.toml.template        # include_str! 内嵌；改后需 touch 所属 .rs 才重编

docs/{决策记录,项目记忆,项目接续指南,用户档案}.md
tools/continuity/*
```
