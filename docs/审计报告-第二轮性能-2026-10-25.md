## 4. 附件内存

`AttachmentSource::File` 的 `read()` 是 `std::fs::read` 整文件；MIME 构建期间 `Vec<u8>` 与编码后的正文可能同时存在。C# 版同样把 `ContentStream` 复制进 `MemoryBlockStream`，所以不是 Rust 独有回归；但 Rust 版缺少上限。建议先加 `max_attachment_bytes`（默认 25MB 或按业务），再评估流式 Body。

## 7. 建议

1. 先做 fallback 单次快照、`send_box_routed` 单次快照、毒化锁恢复（低风险、可测）。
2. 再加附件上限、队列上限/`stop_timeout`（资源安全）。
3. 不急于做 SMTP 连接池：当前发送频率低，C# 也是每次新建连接；`TlsParameters::new` 仅 2.3µs，不是瓶颈。
