## 结构与关键事实

```
src/{lib,error,settings,message,sender/{mod,smtp,null},queue,mailer}.rs
res/Mail.toml.template        # include_str!；改模板后需 touch 所属 .rs 才重编
tests/mail_e2e.rs             # 内置假 SMTP 服务器（EHLO/MAIL/RCPT/DATA）
examples/send_mail.rs
docs/* · tools/continuity/*
```

- 配置：`Config/Mail.toml`，PascalCase 键名与 C# `Mail.config` 对齐；`[[Data]]` 账号数组用
  `TomlConfig::save_with_arrays` 写回（保留注释）。
- `SecureSocketOption`：空=Auto（按账号 `IsSSL`：true→SslOnConnect，false→STARTTLS 可用则升级），
  也可 None/SslOnConnect/StartTls。
- 多账号：默认（`IsDefault` 且启用）优先，失败按顺序轮换；全部失败 `MailError::AllFailed`。
- 后缀路由：`EmailSuffix` 逗号/分号分隔，`route_for`/`send_box_routed` 自动匹配。
- Bcc 只出现在信封（RCPT TO），不写正文头（协议与 lettre 行为）。
- 队列用 `Condvar`：入队立即唤醒；停止用 `dequeue_timeout_while` 防丢失唤醒。
- 日志只记发送成功/失败/账号切换。
